## `security-mindset`

I’m interested in understanding the full lifecycle of an application—not only its features, but also its trust boundaries, failure modes, and security posture.

```text
        IDEA
         |
         v
    ARCHITECTURE
         |
         v
  BUILD  --->  TEST
    ^            |
    |            v
  IMPROVE <--- REVIEW
         |
         v
   SHIP SAFELY
```

Current areas of exploration:

- Web application and API security
- HTTP security headers and configuration weaknesses
- Authentication, authorization, and data protection
- AI application architecture and evaluation
- Secure-by-design development and automation

*Security tools should be used responsibly and only on systems you own or have permission to test.*
